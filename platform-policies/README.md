# Reviewed platform policy registry

Facts are paraphrases reviewed from official pages on 2026-10-07. The stored
`confidence: 1` means the reviewer found support for the documentation statement,
not statistical certainty about applicability or actual processing of a file.
Source scope is mandatory. Coverage is partial. False facts and missing facts
are different: a false fact documents a specific exception; a missing field is
unknown. URLs are never presented as evidence without a reviewed fact.

`profiles.json` is the cached version used during the demo. No live retrieval,
embeddings, model extraction or scraping is required. To refresh, open the
source, review current text and scope, update the fact and date, run tests and
commit the reviewed change. `POLICY_REFRESH_ENABLED` is reserved, not implemented.
